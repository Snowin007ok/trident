# How the app data was produced

**Date:** 21 September 2026
**Source (read-only, never modified):** `~/Documents/TRIDENT_DATABASE_PREP`

- `catalog-v2.1.json`
- `books-v2.1.jsonl`
- `chunks-v2.1.jsonl`
- `history-index-validation-v2.1.md`

**Output:** the four files in `TRIDENT_APP/data/`.

Nothing in `TRIDENT_DATABASE_PREP` or `APP DATABASE` was written to, renamed or deleted. All
51 source PDFs were re-hashed after this work and are unchanged.

---

## What the verified index contains

`chunks-v2.1.jsonl` holds **1,026 verified passages across 12 books** — the history-only index
produced by the v2.1 split, with the two Political Science books already set aside.

## What was exported, and why so little

The prototype ships **20 lesson excerpts, 42 questions and 7 stories** — not the full corpus.
That is deliberate. Placing 1,026 passages in a browser-accessible folder would put the whole
extracted text of twelve copyrighted textbooks on any machine that serves this app. The full
index stays in `TRIDENT_DATABASE_PREP`, outside the web root, for the protected retrieval
backend that comes later.

| File | Contents | Drawn from |
|---|---|---|
| `library.json` | 12 books, their chapters, class availability, path descriptions | `books-v2.1.jsonl`, chapter titles aggregated from `chunks-v2.1.jsonl` |
| `lessons.json` | 20 lessons, each with one short verbatim excerpt | 20 individually selected passages |
| `questions.json` | 42 questions in 5 formats | hand-written from those same passages |
| `stories.json` | 7 stories with 3-question mini-quizzes | hand-written from those same passages |

## Method

1. **Books.** Each record in `books-v2.1.jsonl` became a `library.json` entry. Internal fields
   were dropped (see below) and a **new public id** was minted for each book — `tn-9-ss`,
   `cbse-6-our-pasts-1` and so on — rather than reusing the internal `book_id`, which is
   derived from a filesystem path hash.

2. **Chapters.** Chapter labels were aggregated from the `chapter_title` field of the verified
   chunks, but only where they are trustworthy. In four books the detector latched onto unit
   markers that repeat across the History, Geography and Civics sections, so their page ranges
   overlap and the labels cannot be relied on. Those books carry `chaptersDetected: false`, an
   empty chapter list and a plain-English note; their lessons cite page numbers instead. The
   app says "Chapter title not recorded in the source" rather than inventing one.

3. **Lesson excerpts.** Twenty passages were read in full and one short span was taken from
   each, **verbatim**. Line wrapping from the PDF was joined into paragraphs — no words were
   added, removed, reordered or corrected. Where the printed book contains a typo, the typo is
   preserved. Each excerpt carries book, board, class, chapter (where trustworthy) and page
   range.

4. **Key points and timelines** restate facts that appear in the excerpt shown directly above
   them on the same screen, so a reader can check every one against the quoted text.

5. **Questions.** All 42 were written by hand against a specific excerpt and checked against
   it. No question was generated by a language model. Every question carries its correct
   answer, an explanation, and the book, chapter and page it came from. Where two verified
   books describe the same event slightly differently, no question was written on the point of
   difference.

6. **Stories.** Seven short editorial retellings. These are the only prose in the app written
   by TRIDENT rather than quoted, and each is labelled as such inside the app. Every fact in a
   story comes from the passages cited at its foot; nothing was added from outside them.

## What was removed

| Removed | Why |
|---|---|
| Absolute filesystem paths (`source_path`) | Internal, and exposes the user's directory layout |
| SHA-256 hashes | Internal integrity data, meaningless to a learner |
| `text_quality`, `ocr_required`, `duplicate_status`, `review_reasons`, `status` | Internal quality-control fields |
| Internal `book_id` / `chunk_id` values | Path-derived; replaced with clean public ids |
| Full PDF text | 1,026 passages stay outside the web root |
| Political Science content | The two State Board Political Science books are excluded from the history index |
| TNPSC Tamil study material | Text-layer verification failed; `chunks-unverified.jsonl` was never read |
| Tamil OCR pilot output | Unverified; `chunks-tamil-ocr-unverified.jsonl` was never read |
| OCR-pending books | No usable text layer, nothing to quote |
| Symbol-font books (CBSE class 8, 9, 11, 12 Part III) | Extraction is mojibake |
| `Since-Independence.pdf` | Front matter only; the chapters are not in the file |

Automated checks over the shipped `data/` folder confirm: **no Tamil-script characters, no
absolute paths, no hashes, no Political Science book or citation.** The phrase "Political
Science" appears once, in the plain-English notice explaining why class 11 is empty.

Class 11 has none — that is the real state of the verified index, and the library says so.
Class 12 has CBSE only, and is marked **Limited coverage**.

Question formats: 16 multiple choice, 8 identify-the-date, 6 cause and consequence, 4 match
person and event, 5 chronological ordering, plus three multi-book matching sets. At five
questions a day the bank gives roughly eight distinct daily sets before repetition, and the
selection always draws one question per format where possible.

## Rebuilding

The export was assembled by hand, passage by passage, because every excerpt had to be read
before it could be quoted and every question had to be checked against the text. It is not a
scripted transform, and re-running a script would not reproduce the editorial judgements. To
extend it, open `chunks-v2.1.jsonl`, choose a passage, and add a lesson entry with its exact
book, chapter and page range.
